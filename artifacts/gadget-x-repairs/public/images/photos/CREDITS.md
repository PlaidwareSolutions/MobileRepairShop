## Re-sourcing or replacing a photo

1. Pick a new photo from Pexels / Unsplash / Pixabay (commercial-free, no
   recognizable brand logos, no watermarks).
2. Save the high-res original (≥ 1920w) somewhere temporary.
3. Crop to the listed aspect ratio and export two JPEGs at q≈82:
   - `<slug>-640.jpg`  (640px wide)
   - `<slug>-1024.jpg` (1024px wide)
4. Replace the existing files in this folder; the slug stays the same so
   no code changes are needed.
5. Update the row above with the new attribution and source URL.
